작업 일지가 중복 표시되거나 본문의 일정 날짜가 작성일로 표시되는 문제를 수정한 패치입니다. 최소 지원 버전은 **Obsidian Desktop 1.11.5**로 유지합니다.

## 수정 내용

- 작업 일지 카드는 한 곳에서만 표시합니다. 하위 설명 목록마다 같은 전체 카드와 최근/전체 버튼을 반복 생성하지 않습니다.
- 작업 항목 첫머리의 날짜만 작성일로 인식합니다. 본문의 QA 예정일·배포일·참고 날짜를 작성일이나 최신 작업으로 오인하지 않습니다.
- 날짜형 하위 제목과 설명은 하나의 기록으로 묶습니다. 날짜만 있는 기록·날짜 없는 메모·목록·링크·코드를 보존합니다.
- 코드·주석·속성 안의 날짜나 제목을 작업 항목으로 만들지 않습니다. 미완성 코드·주석으로 삭제 범위가 노트 끝까지 커지는 것도 방지합니다.
- 원본 노트와 업무현황이 같은 판독 로직을 사용합니다. 기존 업무현황은 다음 플러그인 로드 시 새 표시 로직으로 갱신합니다.
- 부분 렌더링·새로고침에서 중복 장착을 방지합니다. 원문 위치를 확인할 수 없으면 원문을 숨기지 않습니다.
- 삭제 확인 후 대상 기록의 원문이 바뀌거나 같은 내용이 여럿이라 정확히 구분할 수 없으면 삭제를 거부합니다. 다른 하위 제목·설명·To-Do·회의록을 삭제 범위에 넣지 않습니다.

## 업데이트 방법과 주의사항

1. 중요한 Vault 노트와 설정을 백업합니다.
2. Community plugins에서 업데이트하거나 `main.js`, `manifest.json`, `styles.css` 세 파일만 교체합니다.
3. **Obsidian을 완전히 종료한 뒤 다시 시작합니다.** `data.json`, `organization-pack.json`, `ticket-activity.json`과 업무 자료는 그대로 둡니다.
4. 최근 작업·전체 작업과 업무현황의 최근 작업을 확인합니다. 본문의 QA 예정일 등이 작성일로 표시되지 않아야 합니다.

- 원본 작업 일지를 자동 이동·재작성·삭제하는 업데이트가 아닙니다. 저장된 원문을 보존한 채 판독·표시를 수정합니다.
- **카드의 X는 원본 기록 삭제 버튼입니다.** 중복 화면을 정리하려고 누르지 마세요. 이 패치가 이미 삭제된 기록을 자동 복구하지는 않습니다.
- 추가 로그인·권한 동의가 필요하지 않으며 Jira·ServiceNow의 실제 업무 변경을 수행하지 않습니다.
