Jira 업무 편집과 댓글 기능을 확장하고, INC 티켓 지원 및 자동 갱신 안정성을 개선했습니다. 최소 지원 버전은 **Obsidian Desktop 1.11.5**입니다.

## 새 기능

### Jira 업무 정보 수정

- 업무 선택 후 담당자·보고자·상태·Plan Start Date·기한의 현재 값을 한 화면에서 확인하고 수정할 수 있습니다.
- 담당자와 보고자는 이름으로 검색한 뒤 선택합니다. 저장할 때는 변경한 항목만 Jira에 반영합니다.
- 현재 계정의 편집 권한과 Jira의 허용된 상태 전환을 확인합니다. 추가 필수 입력이 필요한 상태 전환은 Jira 원본에서 진행하도록 안내합니다.
- 미저장 입력은 창 안에서 업무를 바꿔도 유지됩니다. 저장 버튼은 하단에 유지하며 작은 화면에서는 항목을 세로로 배치합니다.
- 다른 사용자의 변경을 감지하면 덮어쓰지 않습니다. 필드 수정과 상태 전환은 별도 요청이므로 일부 반영·결과 미확인을 구분해 안내합니다.

### Jira 댓글 작성·수정

- 기존 댓글을 불러와 수정 전후 내용을 확인하고 같은 댓글에 저장할 수 있습니다. 다른 사용자가 수정했거나 삭제한 댓글은 덮어쓰지 않습니다.
- 첨부 이미지·멘션·복잡한 서식은 보호 표식으로 유지합니다. 해당 요소 자체를 편집하려면 Jira 원본을 사용해 주세요.
- `@` 뒤에 이름을 두 글자 이상 입력하고 검색 결과를 선택하면 실제 Jira 멘션으로 등록합니다. 번역할 때도 선택한 멘션을 보존합니다.
- 댓글 등록·수정 후 최신 목록을 자동으로 불러옵니다. 현재 필터 밖에 있는 새 댓글은 별도로 안내합니다.
- **현재 연결에서는 대댓글 등록을 지원하지 않습니다.** 대댓글 버튼은 제한을 설명하고 정확한 원본 댓글로 이동할 수 있도록 안내합니다. 새 댓글로 몰래 대체 등록하지 않습니다.

### INC 인시던트 지원

- CR·SR 외에 INC 번호로 티켓을 등록하고 갱신할 수 있습니다.
- 인시던트의 영향도·긴급도·요청자·구성 항목·서비스·보류 사유·해결 정보를 지원합니다. 실제 제공 필드는 ServiceNow 설정과 계정 권한에 따릅니다.
- 업무현황·워크노트·To-Do·회의록·AI Wiki와 연결되며, 비어 있는 CR 전용 문서·일정 항목은 생략합니다.
- INC 전용 분석 템플릿이 없으면 인시던트용 기본 안내를 사용합니다. CR 템플릿이나 CR/SR SLA를 임의로 대신 적용하지 않습니다.

## 수정 및 안정성 개선

- **자동 갱신 실패 재시도:** 같은 티켓의 중복 갱신은 기존 작업 결과를 기다리며, 실행 대기를 실패로 집계하지 않습니다. 실제 전체 갱신 실패는 자동 갱신이 활성화된 동안 1·5·15분 간격으로 최대 3회 재시도합니다. 옵시디언이 실행 중이어야 하며 대기 내역은 재시작 후에도 유지됩니다.
- **갱신 결과 구분:** ServiceNow 갱신 성공 후 Jira 조회만 실패한 경우를 별도로 기록합니다. 실패 원인·재시도 일정·최근 실패 이력을 확인할 수 있습니다.
- **Jira 댓글 이미지:** 댓글 안의 이미지를 이슈별 첨부와 연결해 표시하고, 번역 시에도 위치를 유지합니다. 이미지를 확인하지 못하면 안내를 표시합니다.
- **AI 티켓 분석 프롬프트:** 노트 새로고침 중 생성 결과가 사라지거나 로딩만 보이는 문제를 개선했습니다. 기존 결과 보존과 중복 실행 처리를 보완했습니다.
- **긴 작업 일지:** 원본 노트와 관련 팝업의 작업 일지 높이를 제한하고 내부 스크롤을 제공합니다. 동일 내용의 불필요한 재렌더링을 줄이고 스크롤 위치를 보존합니다.
- **작업 일지 중복 표시:** 카드 준비와 원문 렌더링 시점 차이로 기록이 카드 밖에도 보이는 문제를 보완했습니다. 원본 기록을 자동 이동하거나 삭제하지 않습니다.

## 업데이트 안내

1. 중요한 Vault와 설정을 백업합니다.
2. 플러그인을 업데이트하거나 아래 `main.js`, `manifest.json`, `styles.css` 세 파일만 교체합니다.
3. **옵시디언을 완전히 종료한 뒤 다시 시작합니다.**
4. `data.json`, `organization-pack.json`, `ticket-activity.json`과 기존 업무 자료는 삭제하지 마세요.

Jira 변경 기능에는 기존의 선택적 편집 권한 승인이 필요하며 실제 변경은 사용자가 저장·등록 버튼을 눌렀을 때만 수행합니다. 자동 갱신은 Jira 읽기 전용입니다. 결과가 미확인인 쓰기 요청은 자동 재전송하지 않습니다.

검증: 전체 62개 자동 검사와 Jira 편집 화면의 1440·800·480px 브라우저 모의 검수를 수행했습니다. 실제 Jira 업무·댓글을 변경하는 운영 테스트는 수행하지 않았습니다.
