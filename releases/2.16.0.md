2.15.0 이후의 기능 추가와 개선을 정리한 릴리즈입니다. 최소 지원 버전은 **Obsidian Desktop 1.11.5**이며 기존 노트와 설정을 유지하는 호환 업데이트입니다.

## 새 기능

### 활성 업무·휴면·보관 이력 분리

- 업무현황에서 **활성·전체·보관·휴면** 범위를 전환합니다. 종료된 업무는 기본 목록과 정기 갱신에서 분리하여 반복 작업을 줄입니다.
- 기간과 종료 상태는 **전역 설정**으로 관리합니다. 기본 휴면 기준은 원본 티켓을 **3개월 동안 열지 않았고, 의미 있는 변경도 6개월 동안 없는 경우**입니다.
- 최초 사용 시점부터 이력을 수집하며 과거 열람을 추정하지 않습니다. 원본 티켓을 직접 열면 활성화되고, 최근 열람과 미완료 To-Do는 활성 상태를 보호합니다.
- 보관·휴면 업무도 정확한 티켓 번호 검색이나 전체 범위에서 찾을 수 있습니다. 노트와 문서를 이동·삭제하지 않습니다.
- 필요한 내용을 지연 로딩하고 변경되지 않은 내용을 재사용하여 업무현황의 반복 읽기를 줄였습니다.

### 티켓 없는 회의록과 사후 연결

- 주간·공통 회의록을 **티켓 없음**으로 저장합니다. 파일 추가와 Drive 가져오기 모두 지원합니다.
- 티켓을 검색·체크하면 선택 라벨이 표시됩니다. 복수 선택과 개별 해제를 지원하며, 티켓 노트에서 시작하면 현재 티켓이 기본 선택됩니다.
- **티켓 없음**을 체크하면 기존 선택은 모두 지워집니다. 체크 해제 후에도 과거 선택을 자동 복원하지 않습니다.
- 저장 후에도 **티켓 연결**에서 연결·재연결·해제합니다. 회의록을 복제하지 않고 연결된 모든 티켓에서 공유합니다.
- 제목·본문·다른 메타데이터·PDF는 보존합니다. 원본 회의록의 연결을 바꿔도 티켓별 AI 분석본까지 다른 티켓에 재배정하지 않습니다.

### 최신 DS 일정으로 To-Do 생성

- 원본 티켓의 **일정 생성**에서 DS를 다시 내려받고 **Schedule / PROD Schedule**을 선택합니다. 다운로드 실패 시 오래된 파일로 조용히 생성하지 않습니다.
- **Activity·PIC·Start·End**를 확인하고 원하는 일정만 선택하여 To-Do로 만듭니다. 제목은 Activity, 상세는 업무 안내·담당자·일정·DS 근거로 구성합니다.
- 완료 예정일 기준을 **Start / End** 중 선택합니다. 날짜만 있는 일정은 생성 당시의 시각을 넣습니다.
- DS에 없는 **리뷰 준비**도 추가합니다. 목표일을 입력하거나 날짜 없이 생성할 수 있습니다.
- 활성화된 To-Do 상태 설정을 적용하며 동일 일정의 중복 생성을 방지합니다.

### 관련 노트 자동 생성

- 원본 티켓에서 문서 제목을 입력하면 관련 노트 목록과 실제 문서를 생성·연결하고 새 문서를 엽니다.
- 실제 문서에서 상위 목록과 원본 티켓으로 각각 이동합니다. 목록에서도 문서를 추가할 수 있습니다.
- 기존 수동 연결과 메모를 보존하며 중복 제목·연속 생성·부분 실패를 처리합니다.

## 개선 및 수정

### Jira 주간보고 Export

- **To-Do Status 복수 필터**를 추가했습니다. 날짜·검색·완료 제외 조건과 함께 대상을 좁힙니다.
- 메모 입력에 **확인** 버튼과 반영 표시를 추가했습니다. 현재 대상 티켓을 검색하고 입력창 하나에서 편집합니다.
- **한 셀용 텍스트**의 문단 공백, 여러 줄 메모의 들여쓰기, 중첩 목록과 필드·티켓 간격을 수정했습니다.
- 표·JSON 전환 중에도 같은 메모를 유지합니다. 임시 메모는 Export용이며 원본 티켓에 저장하지 않습니다.
- 시작일·종료일 아래 과도한 공백과 좁은 팝업의 날짜칸 잘림·필터/미리보기 겹침을 수정했습니다.

### To-Do·날짜·반응형 화면

- 업무현황과 원본 티켓이 **같은 정렬 설정**을 사용합니다. 기한·등록일·완료일·제목·다음 확인일 기준 등을 선택합니다.
- 플러그인 날짜·시간 입력에 **현재 시간** 버튼을 추가했습니다. 날짜·시간 묶음은 한 번에 설정하고, 좁은 공간에서는 시계 버튼을 표시합니다.
- 전역 **팝업 너비**를 설정합니다. 기본값은 화면의 **75%**이며 사용자가 조정합니다.
- To-Do 편집의 **삭제·내용 복사·원본 티켓 열기·저장**을 스크롤 영역 밖에 고정했습니다. 티켓 없는 항목은 원본 티켓 열기가 비활성화됩니다.
- 제목을 왼쪽으로 정렬하고 갱신·검색·정렬·필터·표시 필드를 일관된 도구 모음으로 정리했습니다.
- 보드/달력 전환을 오른쪽 선택 메뉴로 통합하고 상태 설정의 과도한 너비를 줄였습니다.
- 마지막확인·배포일이 좁게 저장된 기존 열에서도 날짜를 읽을 수 있도록 최소 너비를 보장합니다.
- 회의록 **삭제·티켓 연결**을 같은 행으로 정리했습니다.
- Dataview의 빈 Markdown 요소가 배치에 끼어들어 제목·버튼을 밀어내던 문제를 수정하고 기존 업무현황의 관리 영역도 업데이트합니다.

### Google Drive 문서 검색

- 티켓 번호와 구분자 주변에 공백이 있는 파일명도 FS·DS·UT 후보로 인식합니다.
- 여러 페이지의 검색 결과를 끝까지 조회하고 중복을 제거하여 앞쪽 결과에 없는 문서가 누락되지 않도록 했습니다.

## 업데이트 방법과 주의사항

1. 중요한 Vault 노트와 설정을 백업합니다.
2. Community plugins에서 업데이트하거나 `main.js`, `manifest.json`, `styles.css` 세 파일만 교체합니다.
3. **`data.json`, `organization-pack.json`, `ticket-activity.json`을 삭제하거나 덮어쓰지 않습니다.**
4. 플러그인 또는 Obsidian을 재시작하고 원본 티켓·업무현황·회의록·Jira Export를 확인합니다.

- 보관·휴면 업무의 원격 변경은 정기적으로 조회하지 않습니다. 최신 정보가 필요하면 원본 티켓을 열고 갱신하거나 전체 이력을 포함한 수동 갱신을 사용합니다.
- Google Drive·ServiceNow·번역 기능은 사용자의 권한과 환경에 따라 동작합니다. 조직별 업무 가이드와 AI 템플릿은 별도 팩이 필요합니다.
- Jira Export는 복사할 자료를 만들며 Jira에 댓글을 쓰거나 상태를 변경하지 않습니다.
- 인증 토큰·OAuth JSON·개인 설정·업무가이드팩·Vault 업무 자료는 배포에 포함하지 않습니다.
