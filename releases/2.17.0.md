2.16.0 이후의 기능 추가와 개선을 정리한 릴리즈입니다. 최소 지원 버전은 **Obsidian Desktop 1.11.5**이며 기존 노트와 설정을 유지하는 호환 업데이트입니다.

## 새 기능

### AI Wiki — 선택 사용, 기본 비활성

- 설정 또는 초기 설정 도우미에서 AI Wiki를 선택적으로 켭니다. 조직 팩, ServiceNow·Google 로그인과 별개이며 나중에 설정해도 됩니다.
- 저장 위치는 현재 설정된 **업무 루트와 Wiki 폴더명**을 사용합니다. 특정 프로젝트 폴더에 고정하지 않습니다.
- **작업기록·지식·첨부**를 구분하고 같은 조사에 여러 티켓을 연결합니다. 티켓 없는 작업도 기록할 수 있습니다.
- 업무현황·리본·명령 팔레트·티켓에서 목록을 열고 제목·요약·티켓·주제·날짜·ID를 검색합니다. 최근 기록, 현재 티켓, 주제, 확인 필요 필터를 제공합니다.
- 목록은 메타데이터 캐시와 페이지 나누기를 사용합니다. 전체 Vault 본문을 매번 다시 읽지 않고 로컬 파일 변경을 반영합니다.

### 처음 사용자를 위한 5단계 연결 도우미

- **AI 선택 → 폴더/첨부 준비 → 시작 프롬프트 전달 → 읽기 확인 → 결과**를 차례대로 진행합니다.
- 폴더 경로만 제공하지 않고 **AI에 보낼 준비 요청**과 **시작 프롬프트**를 복사합니다. 기본 사용에 앱 경로나 CLI 명령 입력은 필요하지 않습니다.
- 준비·전달 확인 버튼을 팝업 하단에 고정하여 확인란을 찾기 어려운 문제를 수정했습니다.
- 읽기 확인 결과에 AI 종류, 접근 방식, 확인 시각과 Wiki 위치를 표시합니다. **로컬 파일 읽기 확인**과 **첨부 기반 전달 확인**은 구분합니다.
- 사용 여부·내부 기록 안내 스위치는 즉시 저장합니다. 폴더명만 별도 **적용 전·적용 중·적용됨·실패** 상태와 적용 버튼을 사용합니다.
- 기록은 기본적으로 저장 전 확인을 요청하도록 안내합니다. 별도 내부 기록 허용 안내도 Wiki 안의 요청 관련 기록만 대상으로 합니다.

### 카드·표 목록과 상세 미리보기

- 요약 카드와 **6열 표 목록** 중 선택하고 표시 방식을 저장합니다. 표에서는 제목·날짜 정렬, 고정 머리글과 첫 열을 지원합니다.
- 두 보기에서 같은 검색·필터·페이지를 사용합니다. 긴 경고는 **확인 필요** 배지로 줄이고 상세 팝업에서 펼칩니다.
- 제목을 선택하면 먼저 **읽기 전용 상세 팝업**을 엽니다. 본문·요약·다음 조치·근거 점검 정보를 확인하고 필요할 때만 **원본 노트 열기**를 누릅니다.
- 팝업을 닫아도 목록의 검색·필터·페이지를 유지합니다. 닫기·원본 열기 버튼은 스크롤 영역 밖에 고정합니다.
- 연결된 각 티켓에 **요약 연결됨·아직 연결 안 됨·원본 티켓 없음** 등의 상태를 표시합니다.

### 통일된 작업 기록과 티켓 일지 연결

- 기록 서식에 기록 ID, 실제 확인 가능한 채팅/작업 ID, 날짜, 관련 티켓, 주제, 요청·요약·근거·미확인·다음 조치를 사용합니다.
- **티켓 일지에 요약 추가**는 확인 후 원본 티켓의 기존 작업 일지에 표준 요약과 Wiki 링크를 덧붙입니다. 같은 기록 ID는 중복 추가하지 않습니다.
- Wiki 원문을 복사·이동하거나 티켓 상태·To-Do를 바꾸지 않습니다. 나중에 Wiki를 수정해도 이전 일지 요약이 자동으로 바뀌지는 않습니다.
- 누락 항목·중복 ID·근거 확인 필요를 점검합니다. 메타데이터 점검은 AI 결론의 정확성이나 접근할 수 없는 모든 채팅의 기록 여부를 보증하지 않습니다.
- 기존 수동 노트·기록·AI 설정을 자동 이동하거나 덮어쓰지 않습니다. 채팅/작업 ID가 없으면 지어내지 않고 미확인으로 남깁니다.

### Jira Export 전용 편집

- 티켓별 묶기를 켜도 **티켓 없는 To-Do는 각각 독립된 업무**로 내보냅니다.
- 원본이 비어 있는 Ticket No.·Description을 Export에서만 채우거나 기존 티켓 설명·메모 등의 보고용 값을 수정합니다.
- 표의 편집 기능과 한 셀용 텍스트·JSON 편집은 **같은 Export 초안**을 사용합니다. 편집을 반영하면 다른 출력 형식에도 적용됩니다.
- 모드 전환·필터·정렬 중에도 대상별 수정값을 유지합니다. 잘못된 구조·식별 정보는 검증하여 적용을 막고 원래 초안을 보존합니다.
- 원본 값으로 복원할 수 있으며, 내보내기 창을 닫으면 임시 수정값을 버립니다. 원본 티켓 Description·To-Do·ServiceNow·Jira에는 저장하지 않습니다.

## 업데이트 방법과 주의사항

1. 중요한 Vault 노트와 플러그인 설정을 백업합니다.
2. Community plugins에서 업데이트하거나 `main.js`, `manifest.json`, `styles.css` 세 파일만 교체합니다.
3. **`data.json`, `organization-pack.json`, `ticket-activity.json`을 삭제하거나 덮어쓰지 않습니다.**
4. 플러그인 또는 Obsidian을 다시 시작합니다. AI Wiki는 원할 때만 켜고, 기존 사용자는 저장된 위치·연결 상태와 카드/표 목록을 확인합니다.
5. Jira Export에서 티켓 없는 업무가 따로 표시되는지, 수정값이 각 출력 형식에 반영되는지 확인한 뒤 복사합니다.

- AI Wiki의 연결 표시는 **사용자가 진행한 읽기 확인의 이력**이며 상시 로그인·실시간 AI 연결·쓰기 권한 부여가 아닙니다.
- 플러그인은 AI를 백그라운드에서 실행하거나 모든 채팅을 수집하지 않습니다. 프롬프트·노트 자동 전송과 AI API 키 저장도 하지 않습니다.
- 웹 채팅은 로컬 경로만으로 파일을 읽을 수 없습니다. 선택한 AI의 폴더 접근 권한, 승인된 연결 방법 또는 사용자가 선택한 파일 첨부가 필요합니다.
- Wiki 내부 기록 허용은 프롬프트 안내이지 운영체제의 권한 제한 장치가 아닙니다. 원본 티켓·코드·DB·외부 시스템 변경 권한을 부여하지 않습니다.
- Wiki를 끄거나 폴더명을 변경해도 기존 파일은 삭제·이동되지 않습니다. 이미 AI에 전달된 자료의 접근·보관 정책은 해당 서비스에서 별도로 관리합니다.
- 조직 가이드팩·인증 토큰·OAuth JSON·개인 설정·Vault 업무 자료는 공개 배포에 포함하지 않습니다. Jira Export는 복사할 자료만 만들며 Jira에 직접 등록하지 않습니다.
